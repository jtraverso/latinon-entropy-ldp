# Counting Steiner designs with prescribed color profiles

Lean statements and proofs for Theorem 1.1 and Corollary 10.1 of [Paper III, preprint 1.0](https://github.com/jtraverso/latinon-entropy-ldp/releases/tag/steiner-profiles-v1.0). The source modules come from the [Zenodo deposit](https://doi.org/10.5281/zenodo.24501236). The entry points for Palomar are SteinerProfilesChallenge and SteinerProfilesSolution. The paper, companion, original Lean archive and audit are distributed with the preprint.

The Lake dependency KqR75 points to the immutable edition commit in the same repository. The comparator configuration is steiner-profiles-comparator.json.
